Changelog.

Platform releases, runtime versions, connector updates. Dated and signed. Subscribe via RSS at /changelog.atom or the weekly digest email.

APR 15, 2026runtime 2026.04

Temporal reads get first-class type inference

  • new Entity.at(ts) infers the returned entity's schema version from the timestamp. No more casts on historical reads.
  • new Agent replay now takes an optional --with-prompt to test prompt diffs against real runs.
  • fix Resolution scorer was over-weighting geocoded proximity for shared-office tenants. Retrained. +1.8pt precision.
  • fix GraphQL subscriptions occasionally missed the terminal frame on workflow completion. Closed.
APR 01, 2026runtime 2026.03

Policy simulator, hardened

  • new Policy simulator replays against a rolling 14d window by default, emits a per-subject delta report.
  • new New connectors: Workday, Rippling, Ramp, Mercury. All GA.
  • break tend policy apply removed; use tend policy deploy. Shim in place for 30 days.
  • fix Workflow saga compensation ran in forward order on nested sagas. Reversed.
MAR 18, 2026runtime 2026.02

Agent budgets are now per-invocation

  • break @agent(budget=...) is now per-invocation, not per-day. Per-day budgets moved to workspace policy.
  • new BudgetExhausted is a typed event; workflows can subscribe.
  • new Run explorer adds a cost breakdown lane per span.
  • fix Rare CDC connector deadlock on Postgres 16. Patched.
MAR 04, 2026runtime 2026.01

GraphQL subscriptions, BYO-cloud for APAC

  • new GraphQL subscriptions GA. Backpressure-aware, multi-tenant.
  • new BYO-cloud deployments available in APAC (Tokyo, Sydney).
  • new @deprecated field tag. Writes blocked after 90 days.
  • fix Lineage traversal n+1 on deeply-nested computed fields. Memoized.
FEB 19, 2026runtime 2025.12

Migrations are now reversible by default

  • new Every tend deploy produces a reverse-migration artifact. tend rollback uses it.
  • new Ingest pipeline replay from any stage boundary.
  • fix Agent tool registry cached stale JSON schemas for 5 minutes after workspace-level tool updates. Now invalidated per-deploy.
