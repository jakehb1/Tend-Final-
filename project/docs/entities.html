Entities & types.

The full type system: scalars, enums, money, temporal types, relations, collections, lifecycle-bearing entities, and first-class events. Everything is strongly typed, versioned, and checked at compile time.

Enums

Enums are closed sets of string literals. Adding a value is additive and safe. Removing or renaming a value requires an explicit migration.

schemastage: enum("lead", "qual", "evaluation", "closed_won", "closed_lost")

Relations

A relation is an edge with identity. Unlike a foreign key, it can carry its own fields and participate in its own lifecycle.

schema/subscription.tendrelation Subscription {
  from: Account
  to:   Product
  started_at: timestamp
  tier:       enum("starter", "team", "ent")
  mrr:        money
}

Collections

Use collection<T> for one-to-many relationships where the child's identity is meaningful, and list<T> for ordered value arrays.

schemadeals:  collection<Deal>     // typed, query-able, policy-scoped
tags:   list<string>       // ordered values, no identity

Lifecycle

Entities that travel through business states declare a lifecycle block. The compiler refuses transitions not defined there — there's no such thing as an invalid state in production.

schemalifecycle {
  draft     → review     requires author
  review    → approved   requires approver and approver != author
  approved  → published  sets published_at = now()
  published → archived   after 180 days
}

Computed fields

Computed fields are pure functions of other ontology facts. The runtime maintains a dependency graph and invalidates transitively on writes. Compute cost is amortized — the first read after invalidation pays, subsequent reads are O(1).

schemahealth: computed<enum("green", "yellow", "red")> {
  let open_support = count(tickets where status == "open")
  let overdue      = any(invoices where days_overdue > 30)

  if overdue             → "red"
  if open_support > 3   → "yellow"
  else                  → "green"
}

Field tags

Tags attach metadata that the policy layer and UI layer key off of. Tags are not comments — they have type-level consequences.

TagEffect
@piiRead requires pii:read capability. Logged on every access.
@secretNever logged. Encrypted at rest with workspace KMS key.
@indexAdds a secondary index for the named key.
@deprecatedLint warning on read. Blocks new writes after N days.
