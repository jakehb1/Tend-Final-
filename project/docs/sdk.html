tend/docs/sdk

SDK reference.

Python 3.11+ and TypeScript 5+ bindings. Generated from your workspace's ontology schema so every entity, relation, and field is typed at authoring time. No string-typed queries, no untyped responses.

Install

pythonpip install tend-sdk
typescriptnpm install @tend/sdk

Generate typed bindings

The SDK ships with a generic interface. For the typed one that knows your schema, run the generator.

shelltend codegen python   --out ./gen/tend_types.py
tend codegen typescript --out ./gen/tend-types.ts
CI
Commit the generated file. Re-run tend codegen in CI after tend push to catch drift between your app code and your deployed schema.

Client

pythonfrom tend import Client, ontology as o

client = Client.from_env()   # reads TEND_WORKSPACE_TOKEN

# point read
acct = client.get(o.Account, "acct_4102")

# typed query
at_risk = client.query(o.Account).where(
    o.Account.health == "red",
    o.Account.tier in ["mid", "ent"],
).limit(100)

Writes

Writes are explicit transactions. The SDK builds a patch, sends a signed request, and returns the committed entity with its new version and lineage.

pythonwith client.tx() as tx:
    acct = tx.get(o.Account, "acct_4102")
    acct.tier = "ent"
    acct.arr  = Money(140_000, "USD")
    tx.commit(reason="upsell closed")

Declaring agents

See Agents for the full decorator contract. The SDK validates the agent's reads/writes/tools at import and emits a deployable bundle on tend push.

Subscriptions

Open a long-lived connection for ontology change streams. Useful for building realtime dashboards, external sync jobs, or observability hooks.

pythonasync for event in client.subscribe(o.Deal.stage.changed()):
    if event.new_value == "closed_won":
        await internal.notify(event.entity)

Errors

Every SDK error is a typed Python exception (or TypeScript subclass of TendError). There are exactly seven:

ExceptionWhen
PolicyDeniedAccess refused by a policy
ValidationErrorPayload failed schema validation
LifecycleErrorIllegal state transition
BudgetExceededAgent or workflow overspent
ConflictErrorOptimistic concurrency clash
RateLimitedWorkspace rate limit hit
TendErrorBase class, never raised directly

Testing utilities

The SDK ships with tend.testing. An in-memory fake workspace for unit tests. Seed it with entities, invoke your agents synchronously, assert on the write set.

pythonfrom tend.testing import FakeWorkspace

ws = FakeWorkspace(schema="./schema")
ws.seed({o.Account: [{"id": "acc_1", "tier": "mid", "arr": 80_000}]})

with ws.as_subject("bot:test"):
    result = renewal_risk.run(ws.get(o.Account, "acc_1"))

assert ws.writes_to(o.Account.health_note) == 1
