tend/docs/cli

The tend CLI.

One binary, seven top-level commands. Deploys are reversible, diffs are previewable, every mutating command prints a plan before executing. Designed to live in CI as comfortably as on a laptop.

Install

shell# macOS / Linux
curl -fsSL https://get.tend.ai | sh

# or via pip (ships with the SDK)
pip install tend-sdk

Auth

shelltend login --workspace acme
# Opens your browser, SSO, writes a scoped token to ~/.tend/credentials

Top-level commands

CommandPurpose
tend initBootstrap a workspace from a warehouse or blank
tend pushSend local schema + agents to the planner
tend planDiff local vs deployed. Print a migration plan.
tend deployApply the plan to a named target
tend runsTail, replay, or explain runs
tend policyAuthor, simulate, deploy policies
tend migrateRun, rollback, or inspect migrations

The push → plan → deploy flow

shell# 1. validate locally
tend lint
# ✔ 14 entities, 38 relations, 6 computed, 0 warnings

# 2. upload & compile on the planner
tend push

# 3. see what would change
tend plan --target staging
# + Account.health  : computed (new)
# ~ Deal.stage     : enum → enum (values: +"evaluation")
# - Lead           : entity (deprecated, 14d grace)

# 4. apply
tend deploy --target staging --approve-plan ./.tend/plan.json

Runs

shell# live tail
tend runs tail --agent renewal-risk-v3

# replay against a different prompt
tend runs replay run_8f2c --with-prompt ./prompts/renewal-risk-v4.md --diff

# explain a failure
tend runs explain run_8f2c --verbose

Policy

shelltend policy lint   ./policies
tend policy simulate --policy ./policies/eu-pii-read.v5.tend --window 14d
tend policy deploy   --policy ./policies/eu-pii-read.v5.tend --target prod

Migrations

shelltend migrate list
tend migrate apply    v18 --target staging
tend migrate rollback --to v17 --target staging

Configuration

Configuration lives in tend.toml at the project root. CI-safe: every field can be overridden with TEND_* environment variables.

tend.toml[workspace]
id       = "acme"
region   = "us"

[targets.staging]
auto_approve_additive = true

[targets.production]
auto_approve_additive = false
require_approvers     = 2

[codegen]
python     = "./gen/tend_types.py"
typescript = "./gen/tend-types.ts"

Exit codes

CodeMeaning
0Success
1Validation error (schema, policy, or local file)
2Planner refused (unsafe diff without migration)
3Deploy failed (remote error, rolled back)
4Auth / permission error
5Rate limited
