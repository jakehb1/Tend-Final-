Durability

  • Write durability: 3-way synchronous replication across AZs. Ack returns only after all 3 acknowledge.
  • Retention: all entity versions retained for 7 years by default. Configurable per entity type down to 90 days.
  • Backups: continuous WAL to customer-owned object storage. Point-in-time restore to any second in the retention window.
  • Availability: 99.95% monthly for Team, 99.99% for Enterprise. Measured at the public API edge.

Incident response

Status at status.tend.ai, per-region. Public postmortems published within 5 business days for any SEV-1. Enterprise customers receive a dedicated RCA within 48 hours.

When you hit a limit
Rate limits return HTTP 429 with a Retry-After header. Entity limits return ResourceExhausted. Either way, email support@withtend.ai — most limits are lifted inside the same business day for active customers.
